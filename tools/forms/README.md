# Form files

UBO form files (`*.ubo-form.json`) hold a whole free-standing form: settings, scoring (score areas and profiles),
sections and fields. Load one in any UBO through the admin: **Forms → New form → Start from a form file**. It
creates a draft; review it, then **Publish**. Make one from any form with **⋮ → Export form file** on its page.

- `mission-tech-compass-v2.ubo-form.json`: Mission Tech Compass v2 (17 scored questions in 5 areas, 7 unscored).
- `client-information-form.ubo-form.json`: Client Information Form (12 sections, 174 fields, repeating groups for contacts,
  providers, diagnoses, medications, hospitalizations, siblings and children). A client intake form: a new result each
  time (category Intake), and public submissions can create new clients. Publish it before using a public link.
