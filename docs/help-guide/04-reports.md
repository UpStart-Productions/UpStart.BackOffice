# Reports

**Reports** in the left nav opens reporting views for the tenant (content depends on enabled reports and role access). Users without the Reports area in their role do not see this menu item.

Pick a period (and optionally a client and project), then **Run report**. The same client and project filters apply on every tab after you run (including **Invoices**, which lists only invoices that have at least one line for the selected project). Tabs: **Time**, **Invoices**, **Expenses**, **Tasks**, and with the Care module on, **Scheduled vs actual**.

On the **Time** tab, client and project names in the tables are links. When a single project is selected, the detail list is titled **Time entries for** that project (also a link).

- **Expenses**: placeholder for now (summary cards and detail reporting coming soon).

- With Care on, the **Time** filter narrows time to **Visit time** (time from visits) or **Other time**.
- **Scheduled vs actual**: per worker and client, hours on scheduled shifts against hours on finished visits, the difference, missed shifts (ended with no visit) and visits with no shift, with totals. A client's name opens their Care tab.
