# CRM (Clients, Contacts, Pipeline, Bookings, Network, Inbox)

## Clients

**Clients** lists client organizations. Use **New Client** to add one. Row menu (⋮) on the left opens edit and other actions. Search is on the far right of the toolbar.

## Contacts

**Contacts** lists people. **New Contact** opens a dialog. **Needs review** filters auto-created contacts from email. Search on the far right.

## Pipeline

**Client Pipeline** shows leads in columns by stage. **New Lead** adds a lead. Drag cards between columns to change stage when permitted.

## Bookings

**Bookings** manages appointment types and bookings. Admins configure booking types under **Bookings** (types sub-route).

## Network

**Network** is a company rolodex. **New Company** adds a row. **Referral-ready only** filters the list. Primary contact avatar appears in the first column.

## Inbox

**Inbox** (unfiled) lists emails that could not be auto-filed. Search on the far right. Use row actions to file or manage messages.
